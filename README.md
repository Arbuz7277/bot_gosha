It's telegram bot "Gosha". He is economical with in-game currency "Coin". All handlers located in directory "handlers".


Steps for start:
  1. Downloading all libaries: "pip3 -r install requirements.txt"
  2. Make the file work: "chmod +x run.sh"
  3. Run the file: "./run.sh"


Notes:
  - 'run.sh' uses venv. You can delete this, if you don't need it.
  - This bot is for Linux. Not tested on Windows.
